# OCN Sales Desk

The Sales desk plugin for Claude, used by the OCN sales team.

## Install

1. In the Claude desktop app, open **Plugins** in the left sidebar.
2. Click **Add**, then **Add marketplace**, then **Add from a repository**.
3. Enter `highhouse-agency/sales-desk`, leave **Sync automatically** on, and click **Sync**.
4. Add **Sales Desk**.

The quick start guide covers the rest of setup.

Current version: 1.1.0
