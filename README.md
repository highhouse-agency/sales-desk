# OCN Sales Desk

The Sales desk plugin for Claude, used by the OCN sales team.

## Install

1. In the Claude desktop app or at claude.ai, open **Customize**, then **Plugins**.
2. Choose **Add**, then **Add marketplace**, and enter `highhouse-agency/sales-desk`.
3. Turn on **Sync automatically** so new versions install themselves.
4. Install **Sales desk**.

The quick start guide covers the rest of setup.

Current version: 1.0.2
